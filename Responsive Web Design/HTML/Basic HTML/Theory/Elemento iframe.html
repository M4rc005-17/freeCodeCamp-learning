Un elemento rimpiazzato è un elemento il quale contenuto è determinato da una risorsa esterna invece di CSS stesso. CSS, Cascading Style Sheets, è usato per aggiungere stile alle pagine web. Esempi comuni di elementi rimpiazzati includono le immagini, iframe e elementi video. Con elementi rimpiazzati, puoi controllare la posizione o il layout di un elemento. Ma il CSS non può modificare direttamente il contenuto di quell'elemento. Considera un elemento "img" che contiene un immagine nella tua pagina web. L'elemento stesso è rimpiazzato con un oggetto esterno: l'immagine. Il tuo CSS può controllare cose come la posizione dell'immagine, o applicare un filtro ad essa, ma non può modificare l'immagine stessa. Un esempio più robusto potrebbe essere l'elemento "iframe" che serve per includere un sito esterno sulla tua pagina web. L'elemento stesso è rimpiazzato con un oggetto esterno: il sito. Il tuo CSS puoò cambiare la posizione del sito incluso, ma non può cambiare il contenuto del sito. Se il sito incluso dovessere avere un elemento "h1", il CSS non sarebbe in grado di modificare quell'elemento "h1". Non puoi cambiare dimenzione, colore del font, eccettera. Ci sono altri elementi rimpiazzati, come "video", e "embed". E alcuni elementi si comportano come elementi rimpiazzati sotto determinate circostanze. Questo tipo di "input" è considerato un elemento rimpiazzato, ma altri tipi di "input" come il "text" o "email" non sono elementi rimpiazzati L'elemento "iframe" sta per inline frame. È un elemento inline usato per contenere altri contenuti HTML direttamente nella pagina HTML. Quel contenuto HTML potrebbe essere un video, una mappa, altri elementi HTML o addirittura un'altra pagina web. L'attributo "src" specifica l'URL della pagina che vuoi includere. L'attributo "width" specifica la larghezza dell'"iframe". L'attributo "height" specifica l'altezza dell'"iframe". L'attributo "allowfullscreen" permette all'utente di mettere l'"iframe" a schermo intero. Inoltre è una buona pratica specificare un attributo "title" per l'"iframe", dato che è importante per l'accessibilità. L'attributo "allow" ti permette di definire cosa può fare o cosa non può fare un "iframe". Questa è chiamata una allowlist. Aggiungere una "clipboard-write" permette alla pagina inclusa di scrivere oggetti sulla tua clipboard. Gli oggetti in una allowlist possono essere separati da un punto e virgola o spazi, ed entrambi possono essere usati insieme. I video possono arrivare dappertutto, non deve essere per forza un video da youtube. Non dimenticare che si possono inserire anche delle mappe, delle pagine web o HTML diretto, all'interno dell'elemento "iframe".
